# 🤖 Career Twin AI

> AI Powered Career Recommendation System using Machine Learning & Flask

---

## 📌 About

Career Twin AI is an intelligent web application that recommends the most suitable career based on a student's skills, interests, education and abilities.

The system uses Machine Learning to analyze user inputs and predicts the best career path along with recommendations.

---

## 🚀 Features

✅ User Registration & Login

✅ AI Career Prediction

✅ Top 3 Career Recommendations

✅ Career Match Score

✅ Skill Gap Analysis

✅ Personalized Learning Roadmap

✅ Prediction History

✅ Professional PDF Report

✅ Courses Recommendation

✅ Project Recommendation

✅ Responsive Dashboard
